# 🎙️ AI-Powered Voice Assistant Android Application

## 🌐 Project Overview
The **AI-Powered Voice Assistant Android Application** is a touchless mobile application that integrates with the **Gemini API** for natural language processing and AI-driven responses. It allows users to interact with their Android devices purely through voice commands to perform various tasks like making phone calls, opening apps, browsing the web, and performing complex calculations — all without touching the device.

---

## 🧠 Project Description
The app is designed to offer hands-free interaction with an Android device using advanced AI algorithms for voice recognition and task execution. Leveraging the **Gemini API**, the app converts natural language speech into actionable commands.

### Key Functionalities:
- 📞 Make phone calls using voice commands.
- ➗ Perform complex calculations.
- 📱 Open applications and navigate the device.
- 🌐 Browse the internet or search content without touch.
- 💬 AI-driven responses to user queries.

---

## ⚙️ Tech Stack
- **Frontend:** Android Studio (Java)  
- **Backend:** Spring Boot (REST APIs for data processing)  
- **Database:** MySQL (For storing user preferences, query history, etc.)  
- **NLP:** Gemini API for natural language processing and response generation

---

## ✨ Key Features:
- **Voice Recognition:** Users can issue commands like "Call John" or "Open Facebook."
- **Task Automation:** Complex tasks like calculations, searching the web, or controlling device functions can be done by voice.
- **User Data Storage:** Preferences and task history are stored in the database for a personalized experience.
- **Hands-free Interaction:** Fully hands-free operation with zero need for touching the device.

---

## 🚀 Installation & Setup
